# DaySpark

DaySpark will help people choose what to do based on their mood, energy, available time, and budget.

## Sprint 0

This repository contains the initial React, TypeScript, Vite, Tailwind CSS, Vitest, and React Testing Library setup. It intentionally contains no recommendation engine, authentication, or backend.

## Commands

- `npm run dev` — start the development server
- `npm run build` — type-check and create a production build
- `npm run lint` — lint the codebase with ESLint
- `npm run test` — run the Vitest suite once
- `npm run test:watch` — run tests in watch mode
